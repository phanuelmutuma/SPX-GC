# Desktop downloads

Prebuilt Mac, Windows, and Linux apps are published on the
**[GitHub Releases](https://github.com/phanuelmutuma/SPX-GC/releases)** page — not in this folder.

**Latest:** [v1.4.2](https://github.com/phanuelmutuma/SPX-GC/releases/tag/v1.4.2)

To rebuild locally: `npm run build:macos`, `npm run build:windows`, or `npm run build:linux`.
To publish a new GitHub Release, push a tag such as `v1.4.3`.
